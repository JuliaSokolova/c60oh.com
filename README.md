# C60(OH) Labs Website v2

Ready for GitHub Pages.

## Publish
1. Back up the current repository.
2. Copy `index.html`, `style.css`, `script.js`, `CNAME`, and the `assets` folder into the repository root.
3. Commit and push to the `main` branch.
4. GitHub Pages should redeploy automatically.

## Important
The Early Access form opens a pre-addressed email to `info@c60ohlabs.com`.
Change that address in both `index.html` and `script.js` if needed.
